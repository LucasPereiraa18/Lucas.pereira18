# Ponto Líder v2.0.0

Pacote completo consolidado do Ponto Líder com o módulo Líder Pulse.

Inclui:
- Integração Secullum e funcionalidades existentes do Ponto Líder.
- Ranking mensal, bonificação, Vida/assiduidade e Pontualidade.
- Execução de tarefas e Nota Coletiva.
- XP, níveis, moedas, conquistas, loja e histórico.
- Configurações de gamificação.
- Migration Supabase `20261029_0005_pulse_gamification.sql`.
- Endpoint público `GET /api/version` para conferência do release.

Este pacote não contém `.env`, senhas ou chaves privadas.
